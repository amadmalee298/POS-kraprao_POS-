## โปรเจกต์
- แอป POS ร้าน "ครัวกะเพรา" (React + Vite + TypeScript)
- repo: amadmalee298/POS-kraprao_POS-
- แอป: GitHub Pages · เซิร์ฟเวอร์: Vercel (pos-kraprao-pos.vercel.app) · ฐานข้อมูล: Firestore (krua-kaprao-pos)
- ทำงานบน branch `claude/code-review-vovllb` เริ่มจาก main ล่าสุดทุกครั้ง

## ขั้นตอนทุกครั้งที่แก้แอป
1. แก้โค้ด → `npx tsc --noEmit -p .` + `npx vitest run` (ทั้งชุด) + `npx vite build` ต้องผ่านหมด
2. อัปเดต `docs/workflow/flow.html` (กล่องที่เปลี่ยน + บรรทัด "อัปเดตล่าสุด") → `node docs/workflow/render.cjs`
3. commit → push → เปิด PR → merge เข้า main เองได้เลย → รอ "Deploy to GitHub Pages" ผ่าน
4. ส่งรูป `docs/workflow/workflow.png` ให้เจ้าของทุกครั้ง · รายงานเป็นภาษาไทย
5. ถ้าเจ้าของบอก "ยังไม่ต้องทำจริง" = เสนอ / ทำภาพตัวอย่างเท่านั้น

## กฎความปลอดภัย
- ห้ามวางในแชตหรือ Telegram: API key (sk-ant-), คีย์ Omise/Opn, secret ของ Apps Script, ลิงก์ /exec, ลิงก์ MCP, ลิงก์แจ้งเงินเข้า

- ระวังโควตา Firestore (อ่าน 50k / เขียน 20k ต่อวัน รีเซ็ต 15:00 น.) ห้ามมีลูปเขียนหรือการอ่านหนัก

## ระบบชำระเงิน (ตกลงล่าสุด)
- บิลเป็น "จ่ายแล้ว" เองได้เฉพาะเมื่อระบบยืนยันเงินเข้า:
  - Opn: เซิร์ฟเวอร์ถาม Opn เอง
  - Merchant Pro: แจ้งเงินเข้าที่ยืนยันว่ามาจากแอปธนาคาร
- รูปสลิปเปลี่ยนเป็นจ่ายแล้วไม่ได้ (AI ตรวจสลิปเป็นแค่ข้อมูลช่วยดู)
- ไม่มีแจ้งเงินเข้าที่ยืนยันแล้ว → แคชเชียร์ต้องกดยืนยันว่าดูยอดในแอปธนาคารแล้ว
- เงินเข้า 1 รายการใช้กับบิลเดียว (จองไว้ 10 นาที) · อ่านยอดเงินเข้า ไม่เอายอดคงเหลือหรือค่าธรรมเนียม
- เซิร์ฟเวอร์ Opn ใช้ได้เฉพาะเครื่องที่เข้าบัญชีร้าน
- ลิงก์ MCP และลิงก์แจ้งเงินเข้า: ยกเลิกแล้วใช้ไม่ได้ภายใน 30 วินาที · ใส่คีย์ผิดซ้ำต้องรอ 1 นาที

## ทำเสร็จแล้ว (ช่วงหลัง)
- ฟอร์มค่าใช้จ่ายแบบใหม่:
  - รายการชุดเดียวใช้ทั้งบัญชีและสต็อก (แตะชิปวัตถุดิบเพื่อเพิ่มแถว)
  - ยอดรวมคิดเอง (ต้องใส่ราคาครบ) หรือกด "แก้ยอด"
  - ส่วนที่ไม่ค่อยใช้อยู่ใน "ตัวเลือกเพิ่มเติม" · ปุ่ม "บันทึก ฿ยอด" ติดล่างจอ
- หน้าแรกการเงิน "วันนี้ระบบทำให้แล้ว": การ์ด 4 ใบ + รายการ "รอคนตัดสินใจ" + ปุ่ม "ปิดวัน" (ตรวจแล้วส่งสรุปเข้า Telegram)
- "บิลนี้ไปไหนต่อ" ในออเดอร์และค่าใช้จ่าย: สต็อก → บัญชี JE-เลขบิล → ภ.พ.30 ช่อง 5/7
- ภ.พ.30 เรียงตามช่อง 1–9 ของแบบฟอร์ม
- ระบบ MCP สำหรับ Claude · แจ้งเงินเข้า Merchant Pro ผ่าน MacroDroid
