④ ที่เก็บข้อมูลและการซิงก์

ในเครื่อง: ไม่เก็บข้อมูลร้านแล้วเปิดแอป → โหลดจากคลาวด์ทุกครั้ง (ถือไว้ในหน่วยความจำ)
เครื่องเดิม: ส่งทุกอย่างที่ค้างขึ้นคลาวด์ให้ครบก่อน → ลบสำเนาในเครื่อง
ต้องต่อเน็ต + เชื่อมบัญชีร้าน จึงเข้าระบบได้ (ไม่มี PIN 1234 ระหว่างรอ)
ลืม PIN → ยืนยันด้วยรหัสผ่านบัญชีร้าน แล้วตั้ง PIN ใหม่
PIN ไม่ตรงกันระหว่างเครื่อง → ใช้ได้ทั้งคู่จนตั้งใหม่
เก็บไว้แค่การเข้าระบบบัญชีร้าน และตัวเลือกเล็กๆ ของเครื่อง
